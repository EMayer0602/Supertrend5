FlexQuery Aktivierung - Schritt für Schritt (Deutsch)
1. Einloggen
Gehe zu: https://www.interactivebrokers.com/sso/Login

Login mit deinen IB-Zugangsdaten

2. FlexQuery Report erstellen
Nach dem Login siehst du das Account Management (Kontoverwaltung).

Navigation:

Menü → Performance & Berichte → Flex-Abfragen

oder auf Englisch:

Menu → Performance & Reports → Flex Queries

Falls du es nicht findest:

Oben rechts gibt es eine Suchleiste (Lupe)
Tippe ein: "Flex"
Klicke auf "Flex-Abfragen" oder "Flex Queries"
3. Neue Abfrage erstellen
Klicke auf "Erstellen" oder "Create"

Wähle "Aktivitäts-Flex-Abfrage" (Activity Flex Query)

Name: z.B. Trades

Wähle diese Felder aus:

✅ Handelsdatum (Trade Date)
✅ Symbol
✅ Kauf/Verkauf (Buy/Sell)
✅ Menge (Quantity)
✅ Preis (Price)
✅ Provision (Commission)
✅ Realisierter G&V (Realized P&L)
Speichern → Notiere die Query ID (Abfrage-ID)

4. Flex Web Service aktivieren
Menü → Einstellungen → Benutzereinstellungen → Flex Web Service

oder suche nach "Flex Web Service"

Aktivieren anklicken
Token kopieren (das ist ein langer Code)
5. In deinem Script eingeben
python generate_dashboard.py --setup-flex

Dann eingeben:

Token: (den langen Code von Schritt 4)
Query ID: (die Nummer von Schritt 3)
